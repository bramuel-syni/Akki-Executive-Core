# Sprint Memo Convention

Every phase-close report must, before being declared shipped:
1. Update `/app/memory/DEV_PIPELINE.md` §4 Invariant Ladder + §5 Surface Ratchet + §9 Phase History.
2. Confirm the update via grep/diff evidence in the phase-close report.
3. Cross-link the sprint memo at `/app/memory/sprints/<phase>.md`.
